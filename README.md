# Таамим

Приложение для изучения знаков кантилляции (таамим) и пения Торы, традиция LJG.

Статический сайт без сборки: `index.html` + папки `img/` (ноты по строкам) и `audio/` (43 клипа).

## Публикация на Vercel
1. Создайте репозиторий на GitHub и загрузите эти файлы.
2. На vercel.com: Add New, Project, выберите репозиторий.
3. Framework Preset: Other. Build Command и Output Directory оставьте пустыми. Нажмите Deploy.

## Локальный просмотр
`python3 -m http.server` в этой папке, затем http://localhost:8000
